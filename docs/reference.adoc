== Gates

EventBus transports registered metadata automatically; HTTP and Kafka have opt-in adapters. Redis, Elasticsearch, and other unsupported protocols need an application integration if metadata must cross the wire. Binding a callback only restores local execution context. See link:usage.adoc#_connect_services[service integration examples] and link:transport-configuration.adoc#_carrier_transport[custom carriers].

== Data Items

`ContextChainDataItem` marks an application-owned metadata type. `ContextChainDataService` supplies its wire codec and inbound policy. Start with the link:usage.adoc#_your_own_typed_item[typed item example], then the link:advanced.adoc#_write_a_codec[codec example].
